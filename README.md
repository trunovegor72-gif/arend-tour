Сервис аренды туристического оборудования
Назначение: Консольное приложение для  проката туристического снаряжения. Позволяет вести учёт оборудования, клиентов и заказов, рассчитывать стоимость аренды, отслеживать выдачу и возврат снаряжения.

Целевая аудитория: Сотрудники пунктов проката и магазинов туристического снаряжения.
В перспективе конечные клиенты (через веб-интерфейс).

Предметная область: Аренда туристического оборудования — процесс, при котором клиент выбирает необходимое снаряжение (палатки, рюкзаки, спальники, горелки и т. п.), оформляет заказ на определённый срок, оплачивает и получает оборудование во временное пользование. По истечении срока аренды оборудование возвращается, проверяется его состояние и рассчитывается итоговая стоимость.

Основные сущности: Оборудование — единица снаряжения (название, категория, описание, стоимость аренды за сутки, общее количество, количество доступных единиц).

Категория — тип оборудования (палатки, рюкзаки, спальные мешки, кухонное оборудование и т. д.).

Клиент — арендатор (ФИО, контактный телефон, email).

Заказ (Аренда) — связь клиента с набором оборудования, включающая даты начала и окончания аренды, статус (активна / завершена / просрочена), итоговую стоимость.

Основные функции: Добавление, редактирование и удаление позиций оборудования;
Просмотр каталога оборудования с фильтрацией по категориям и доступности;
Регистрация и редактирование данных клиентов;
Оформление аренды: выбор клиента, добавление нескольких единиц оборудования, указание периода аренды;
Автоматический расчёт стоимости аренды (с учётом количества дней и тарифов);
Возврат оборудования и закрытие заказа с проверкой состояния;
Просмотр списка активных и завершённых аренд;
Сохранение данных в файл (JSON/CSV) для персистентности между запусками;

План развития:
На следующих этапах планируется:
разработка веб-приложения;
подключение базы данных;
реализация пользователей;
разработка API;
контейнеризация приложения;
настройка CI/CD.
